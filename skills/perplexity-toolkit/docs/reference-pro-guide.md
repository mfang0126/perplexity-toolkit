## 三、高效提问模板

### 3.1 事实查询
```
"[具体问题] + [年份] + [数据来源要求]"

示例：
"2026年最受欢迎的Python Web框架是什么？引用GitHub star数和Stack Overflow调查。"
```

### 3.2 深度研究
```
请全面分析 [主题]，包括：
1. [维度1]
2. [维度2]
3. [维度3]
请引用具体数据和来源，给出对比表格。
```

### 3.3 竞品分析
```
分析 [A] vs [B] vs [C]：
1. 定价策略
2. 核心功能差异
3. 用户评价（Reddit/G2/Capterra）
4. 适合场景
用表格对比。
```

### 3.4 技术选型
```
我需要 [场景]，候选 [A, B, C]。
对比：性能、学习曲线、社区支持、维护风险、成本。
给出推荐和理由。
```

## 四、⚠️ 社区报告的已知问题（必读）

> 来源：Reddit 297+ 帖子、Twitter 投诉、官方社区、媒体报告、浏览器实操验证

### 🔴 严重问题

**4.1 编造答案和引用 — 最高频投诉**
- 用户报告 ~80% 答案声称的信息"根本不存在"
- 引用链接指向 404 或无相关内容
- 独立测试：Deep Research 编造论文和日期
- 新闻引用研究：**37% 时间引用错误**（8 个 AI 搜索中最好，但仍超 1/3）
- **应对**：永远验证引用链接是否真实可访问；关键事实至少交叉验证 2 个来源

**4.2 医疗信息造假 — 安全风险**
- 编造医生评论（假 5 星评分、不存在的引用）
- 学术研究：72% 引用被核查为伪造
- **应对**：医疗/法律问题不要依赖 Perplexity，去官方来源

**4.3 答案错误 + 被动自纠**
- 基础查询和研究查询都会出错
- 被质疑后才承认错误并给出正确答案
- 错误率在近期月份**上升**
- **应对**：追问"你确定吗？能验证一下吗？" — 触发自纠机制

**4.4 Pro 订阅陷阱**
- $200 年费自动续费，AI 客服"Sam"拒绝退款（72 小时窗口期）
- AI 客服拒绝转人工
- 多用户报告被双重扣费
- 区域退款政策：EU/UK 14 天，其他 72 小时
- **应对**：订阅后立刻关闭自动续费；保留付款截图

### 🟡 中等问题

**4.5 日期过滤失灵**
- 请求特定日期范围，返回错误日期的内容
- **应对**：在 prompt 中强调日期，手动检查结果日期

**4.6 Deep Research "/" 前缀**
- 激活模式时输入框残留 "/" 字符
- Perplexity 会自动处理，不影响结果质量
- **已知但无害**

**4.7 模型切换偶尔不生效**
- 切换模型后仍用默认模型回答
- **应对**：刷新页面重试

**4.8 配额不透明**
- Pro/Max 限制是"平均"而非硬数字
- Computer 积分不结转
- **应对**：重度使用时注意剩余额度

### 🟢 小问题

**4.9 历史不可搜索**
- 搜索记录存在但无法搜索/筛选
- Collections 不是真正的知识管理系统
- **应对**：用我们的 `perplexity history` 命令管理

**4.10 突发新闻滞后**
- 过去 1-2 小时的新闻可能搜不到
- **应对**：突发新闻用 Google，不要用 Perplexity

## 五、Pro 用户专属技巧

### 5.1 Pro Search vs 普通搜索
- Pro Search：多步搜索，交叉验证，引用更多
- 普通搜索：单次搜索，速度快
- **Pro 用户默认开启 Pro Search**

### 5.2 Deep Research 是最大杀器
- 相当于研究助理花 5 分钟调研
- 质量 ≈ 初级分析师水平
- **适合**：竞品分析、技术选型、市场调研
- **不适合**：简单事实查询

### 5.3 追问技巧
```
"上面提到的 [X]，能展开说说？"
"有没有 [场景] 的实际案例？"
"这个方案的风险和局限性？"
"你确定吗？能验证一下引用链接吗？"  ← 触发自纠
```

### 5.4 用英文问技术问题
- 英文源质量远高于中文源
- 中文搜索容易命中低质量博客
- **策略**：技术问题用英文问，获取答案后自己翻译

### 5.5 API vs Web（为什么要浏览器自动化）

| 功能 | Web UI | API |
|------|--------|-----|
| Pro Search | ✅ | ❌ |
| Collections | ✅ | ❌ |
| Focus 模式 | ✅ | ❌ |
| 图片生成 | ✅ | ❌ |
| Model Council | ✅ | ❌ |
| Deep Research | ✅ | ✅ |

**结论**：Web-only 功能远多于 API，浏览器自动化是榨干 Perplexity 的唯一完整路径。
