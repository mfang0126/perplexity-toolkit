## 一、模型选择策略

Perplexity Pro 可切换底层模型。不同任务选不同模型：

| 任务类型 | 推荐模型 | 原因 |
|----------|----------|------|
| **日常搜索** | Sonar（默认） | 最快，搜索优化，引用最多 |
| **深度研究** | GPT-4o / Claude 3.5 Sonnet | 推理能力强，长文分析好 |
| **代码/技术** | Claude 3.5 Sonnet | 代码理解最佳 |
| **学术论文** | GPT-4o + Academic Focus | 引用格式规范，来源权威 |
| **创意写作** | Claude 3.5 Sonnet | 文风最好 |
| **数学/逻辑** | GPT-4o | 数学推理更准 |
| **中文搜索** | Sonar | 中文源抓取更好 |
| **多角度对比** | Model Council | 3 个模型同时回答 |

### 切换方式
1. 输入框下方点击模型名 → 下拉选择
2. 或用我们的 CLI：`perplexity search "query" -m deep_research`

## 二、搜索模式详解

| 模式 | 触发方式 | 耗时 | 适合场景 |
|------|----------|------|----------|
| **标准搜索** | 直接输入 | 5-15s | 快速事实查询 |
| **Pro Search** | 默认开启 | 15-30s | 需要多源交叉验证 |
| **Deep Research** | 输入 `/` → 深度研究 | 60-120s | 综合报告、竞品分析、技术选型 |
| **Model Council** | 输入 `/` → 模型委员会 | 20-30s | 争议话题、需要多视角 |
| **Step-by-step** | 输入 `/` → 逐步学习 | 15-20s | 学习新概念、教程 |

## 三、高效提问模板

### 3.1 事实查询（快、准）
```
[具体问题] + [时间范围] + [来源要求]

示例：
"2026年最受欢迎的Python Web框架是什么？请引用GitHub star数和Stack Overflow调查数据。"
```

**技巧：**
- 加年份避免过时信息
- 指定数据来源（GitHub、Reddit、官方文档）
- 用英文问技术问题（英文源质量更高）

### 3.2 深度研究（全面、有引用）
```
请全面分析 [主题]，包括：
1. [维度1]
2. [维度2]
3. [维度3]
请引用具体数据和来源，给出对比表格。

示例：
请全面分析2026年主流AI Agent框架（LangChain、CrewAI、AutoGen、Mastra），
包括架构设计、性能对比、社区活跃度、生产环境案例。
请引用GitHub数据和开发者评价，给出对比表格。
```

**技巧：**
- 列出你关心的维度（框架帮你组织）
- 要求表格对比（Perplexity 表格生成能力强）
- 要求引用（Pro Search 会自动标注来源编号）

### 3.3 竞品分析
```
分析 [产品A] vs [产品B] vs [产品C]：
1. 定价策略
2. 核心功能差异
3. 用户评价（来自Reddit/G2/Capterra）
4. 适合什么场景
请用表格对比。
```

### 3.4 技术选型
```
我需要 [具体场景]，候选方案有 [A, B, C]。
请从以下维度对比：
- 性能基准
- 学习曲线
- 社区支持
- 长期维护风险
- 成本
给出推荐和理由。
```

### 3.5 学习新领域
```
我是一个 [背景] 的开发者，想学习 [领域]。
请给出：
1. 核心概念清单（10个以内）
2. 推荐学习路径
3. 最佳入门资源（附链接）
4. 常见误区
```

## 四、Focus Mode 选择

| Focus | 适合场景 | 效果 |
|-------|----------|------|
| **All**（默认） | 通用搜索 | 全网搜索 |
| **Academic** | 论文、研究 | 优先学术来源（arXiv、Google Scholar） |
| **Writing** | 写作辅助 | 减少搜索，侧重生成 |
| **Math** | 数学问题 | 数学推理优化 |
| **Video** | 视频内容 | 搜索 YouTube 视频和转录 |
| **Social** | 社交媒体 | 搜索 Reddit、Twitter/X |

**切换：** 输入框下方的 Focus 按钮

## 五、Pro 用户专属技巧

### 5.1 Pro Search vs 普通搜索
- Pro Search：多步搜索，交叉验证，引用更多，答案更长
- 普通搜索：单次搜索，速度快
- **Pro 用户默认开启 Pro Search**，别浪费

### 5.2 Deep Research 是最大杀器
- 相当于一个研究助理花 5 分钟帮你调研
- 生成的报告质量 ≈ 初级分析师水平
- **适合**：竞品分析、技术选型、市场调研、学术文献综述
- **不适合**：简单事实查询（杀鸡用牛刀）

### 5.3 追问技巧
Perplexity 支持在搜索结果上追问。好的追问：
```
"上面提到的 [X]，能展开说说吗？"
"有没有 [具体场景] 的实际案例？"
"这个方案的风险和局限性是什么？"
```

### 5.4 用英文问技术问题
- 英文源（Stack Overflow、GitHub、Hacker News）质量远高于中文源
- 中文搜索容易命中低质量博客
- **策略**：技术问题用英文问，获取答案后自己翻译

### 5.5 Collections（收藏集）
- Pro 用户可以创建 Collections，保存搜索结果
- 适合做项目调研、知识库积累
- **我们已自动提取 sources**，不需要手动收藏

## 六、常见陷阱

| 陷阱 | 说明 | 应对 |
|------|------|------|
| **过时信息** | 搜索结果可能引用旧文章 | 加年份限定 |
| **编造来源** | 偶尔引用不存在的链接 | 检查 URL 是否可访问 |
| **英文偏好** | 中文搜索质量不如英文 | 技术问题用英文 |
| **深度研究 "/" 前缀** | 模式激活时输入框残留 "/" | Perplexity 会自动处理，不影响结果 |
| **免费版限制** | Pro Search 每天有次数限制 | Pro 用户无限制 |
| **模型切换不生效** | 偶尔切换后还是用默认模型 | 刷新页面重试 |
